getcwd() - Get Current Working Directory
Programın şu anda hangi dizinde çalıştığını öğrenmek için kullanılır.

Nasıl Çalışır:
	Sistemden mevcut dizin bilgisini alır
	Bu bilgiyi verdiğiniz buffer'a kopyalar
	Buffer'ın adresini geri döndürür

Parametreler:
	buf: Sonucun yazılacağı karakter dizisi (array)
	size: Bu dizinin kaç karakter alabileceğini belirtir

başarısız durumda null döner.

char *result = getcwd(NULL, 0);

Ne Yapar:
	Sistem otomatik olarak yeterli boyutta memory allocate eder
	Current directory path'ini bu memory'ye yazar
	Bu memory'nin adresini döndürür

Avantajları:
	Buffer boyutu hesaplamaya gerek yok
	Uzun path'ler için güvenli
	Otomatik boyutlandırma

Dezavantajları:
	Manuel free() gerekli - memory leak riski



chdir() - Change Directory
Programın çalıştığı dizini değiştirmek için kullanılır.

Nasıl Çalışır:
	Verilen path'e gitmeye çalışır
	Başarılıysa programın working directory'si değişir
	Bu değişiklik sadece program için geçerlidir

Parametreler:
	path: Gidilecek dizinin yolu (string)

!! getcwd() string döndürür, chdir() sadece başarı/başarısızlık


//-------------------------------- ENV --------------------------------\\
pwd = getcwd(NULL, 0);
if (pwd)
{
	clean_envp[0] = ft_strjoin("PWD=", pwd, shell);
	free(pwd);
}
else
	clean_envp[0] = ft_strdup("PWD=/", shell);

Ne zaman else'e girer?
- mevcut dizin silinmiş / izin problemi
Eğer mevcut dizin belirlenemezse en azından geçerli bir PWD değeri set eder.
Bu durumda PWD=/ (root directory) kullanılır çünkü:
	Her sistem'de / directory vardır
	Geçerli bir path'tir
	Program crash etmez
Pratikte çok nadir olur, ama güvenlik için gerekli.


//-------------------------------- EXIT --------------------------------\\
isatty() tam olarak file descriptor'ın bir terminal cihazına bağlı olup olmadığını kontrol eder.

Ne Kontrol Eder:
	File Descriptor'ın Türünü:
		Terminal/TTY: Klavye, ekran gibi interaktif cihazlar
		Regular File: Normal dosyalar
		Pipe: Program arası veri aktarımı
		Socket: Network bağlantıları

isatty() aslında ioctl() sistem çağrısını kullanır:
	Kernel'den Bilgi:
		Kernel her file descriptor için metadata tutar
		Bu metadata'da cihaz türü bilgisi var
		ioctl(TCGETS) terminal-specific bir işlem yapar
		Başarılıysa terminal, başarısızsa değil

Kontrol ettiği: File descriptor'ın terminal cihazı olup olmadığı
Erişim yöntemi: Kernel'deki file descriptor metadata'sını ioctl() ile sorgular
Amaç: Program'ın interactive mı batch modda mı çalıştığını anlamak

TTY (Teletypewriter):Terminal/Console demek. Klavye + ekran kombinasyonu. İnteraktif mod.

Batch Mode (Toplu İşlem): Komutları önceden hazırlanmış dosyadan veya script'ten çalıştırma. 

# Interactive (TTY)
./minishell
minishell$ ls
minishell$ exit

# Batch Mode  
./minishell < commands.txt    # Dosyadan komutlar
echo "ls; exit" | ./minishell # Pipe ile komutlar
./script.sh                   # Script çalıştırma
